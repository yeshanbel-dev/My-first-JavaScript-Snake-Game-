# 🐍 My First JavaScript Snake Game

A classic Snake Game built from scratch to practice my basic programming skills.

## 🌱 About the Project
This project is a huge milestone for my learning journey! Before starting this game, JavaScript logic felt like a completely distant and difficult world to me. By building this step-by-step, I broke through that fear and finally understood how coding logic works in real life. 

## 🧠 What I Learned as a Beginner:
* **Basic Logic:** How to use `if/else` statements to control the snake's movement.
* **Game Coordinates:** Understanding grid layouts and how variables change positions.
* **Problem Solving:** Figuring out how to make the snake grow and how to detect when it hits a wall.
* **Consistency:** Showing up every day and turning hard topics into real skills.

## 🛠️ Tools Used
* HTML5 (Structure)
* CSS3 (Styling)
* JavaScript (Game Logic)
